# Medical--Chatbot
AI-powered medical chatbot that answers health-related questions using a medical encyclopedia, FAISS vector search, LangChain, and Groq LLM.

![image alt](https://github.com/starAditya/Medical--Chatbot/blob/4e564d169ca9b305224f0b7c762bc61ac6d219b7/Screenshot%202026-09-04%20220729.png)

## Features

- Retrieves relevant medical information from a medical encyclopedia PDF.
- Uses FAISS for efficient similarity-based document retrieval.
- Generates clear responses with the Groq large language model.
- Displays the source page numbers used to generate each response.
- Provides an interactive chat interface built with Streamlit.

## Technologies Used

- Python
- Streamlit
- LangChain
- FAISS
- Hugging Face Embeddings
- Groq API
- Sentence Transformers
